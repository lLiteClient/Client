# 🌐 Инструкция: Как запустить сайт LiteClient бесплатно (0 рублей)

Сайт полностью свёрстан в папке `C:\Users\MAIBENBEN\Desktop\liteclient-website`.
Внутри уже лежат все файлы: `index.html`, `styles.css`, `script.js` и сам `LiteClient.exe` для скачивания.

Ниже 2 самых простых способа сделать сайт доступным в интернете **навсегда и бесплатно**:

---

## 🚀 Способ 1: Cloudflare Pages (Самый быстрый, без Git, за 1 минуту)
*Даёт бесплатный красивый домен `liteclient.pages.dev`, мощную защиту от DDoS и самый быстрый CDN в мире.*

1. Зайди на [pages.cloudflare.com](https://pages.cloudflare.com) и зарегистрируй бесплатный аккаунт (или войди).
2. Нажми кнопку **"Create a project"** (Создать проект) -> вкладка **"Direct Upload"** (Прямая загрузка).
3. Введи имя проекта (например, `liteclient-1214`).
4. **Просто перетащи папку `liteclient-website` с рабочего стола** в окно браузера!
5. Нажми **"Deploy site"**.
6. Готово! Через 10 секунд твой сайт работает по адресу `https://liteclient-1214.pages.dev`.

---

## 🐙 Способ 2: GitHub Pages (Классический бесплатный хостинг)
*Даёт бесплатный домен `твой-ник.github.io/liteclient`.*

1. Создай бесплатный репозиторий на [github.com](https://github.com) с именем `liteclient` (выбери Public).
2. Загрузи в него файлы из папки `C:\Users\MAIBENBEN\Desktop\liteclient-website` (`index.html`, `styles.css`, `script.js`).
3. Зайди в **Settings** (Настройки репозитория) -> слева раздел **Pages**.
4. В пункте **Source** выбери ветку `main` (или `master`) и папку `/ (root)`, нажми **Save**.
5. Через 1 минуту сайт будет доступен по ссылке `https://твой-логин.github.io/liteclient/`.

---

## 💻 Локальный просмотр прямо сейчас
Чтобы открыть сайт на своём компьютере прямо сейчас, просто дважды кликни на файл:
`C:\Users\MAIBENBEN\Desktop\liteclient-website\index.html` в любом браузере (Chrome, Edge, Opera, Firefox).
